Combining Old & New Cinema

The webtext is designed to examine both old and new approaches to cinema. As the idea of moving images was created with the zoetrope, and then the film strip was invented, we can see the evolution of cinematic storytelling. The website looks to investigate these core principles using aspects of code that might give insight into the intersection of older film techniques and newer, more accessible coding techniques.
